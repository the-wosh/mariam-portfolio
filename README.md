# Mariam G. Mambuay — AI Video & Motion Design

A static portfolio starter built with HTML, CSS, and JavaScript for GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design and visual styling
- `script.js` — small interaction enhancements

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload these files to the repository root.
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site.

Replace the concept placeholder work with Mariam's real videos, links, contact details, and project descriptions before launch.
